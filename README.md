# Knowledge Vault

Knowledge Vault is a responsive knowledge resource website built with HTML and CSS, featuring a clean layout and organized presentation of learning materials.

## Live Demo

https://farjanayeasminrimi.github.io/Knowledge-Vault/

## Repository

https://github.com/farjanayeasminrimi/Knowledge-Vault

---

## Project Overview

Knowledge Vault is a simple and responsive frontend project designed to organize and display educational or informational resources in a clean and user-friendly way.

---

## Tech Stack

- HTML5
- CSS3

---

## Main Features

- Responsive website design
- Clean and organized layout
- Resource showcase sections
- User-friendly interface
- Mobile-friendly design

---

## Installation & Local Setup

### 1. Clone the Repository

```bash
git clone https://github.com/farjanayeasminrimi/Knowledge-Vault.git
```

### 2. Navigate to the Project Folder

```bash
cd Knowledge-Vault
```

### 3. Open the Project

Open `index.html` in your browser.
